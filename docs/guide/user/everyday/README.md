# Everyday use

You use memors-mcp by talking to Claude. There are no special commands to learn. Say what you
want in your own words, and mention "memors" when you want Claude to use the memory rather than
its general knowledge.

| You want to… | Say something like… | Chapter |
|---|---|---|
| Keep a document or a note | "Save this to memors." | [Saving documents and notes](saving.md) |
| Find something | "What does memors say about our deploy process?" | [Asking questions](asking.md) |
| Record one fact, or correct one | "Remember that the API limit is 100 requests per minute." | [Facts and corrections](facts.md) |
| Remove something | "Forget the old onboarding note; it is wrong." | [Forgetting things](forgetting.md) |
| Keep topics or projects apart | "Save this on the *billing* shelf." | [Keeping work separate](separate.md) |

> **Tip.** Claude works better with the memory once it knows the house rules. The project ships
> a short guide for Claude called `SKILL.md`. Put it in your project, or paste it into a
> conversation, and Claude will search before answering and save what it learns.
