## Live smoke on the v1.0 demo file

Running `memo-mcp ui --no-model` against the knowledge base created in the 1.0 clean-machine
scenario (schema v1 at the time) found two gaps, now fixed and tested:

| Gap | Before | After |
|---|---|---|
| Read-only open of an older-schema file | `no such table: entities` on the home page | `knowledge base needs migration: file is at schema v1, this binary expects v3; run memo-mcp migrate` |
| Entities for documents ingested before 1.1 | none; `/entity/...` 404 | `memo-mcp graph rebuild` re-extracts mentions (1 passage → 1 entity in the test) |

After `migrate`, every route answered 200 on that file; POST 405; a foreign Host header 403.
