## The P8 slices (`internal/eval/compact_test.go`, over both corpora)

Five defects were planted in the platform namespace: two live facts about Quorum Replication
that disagree (agent says three nodes, user says five), a fact whose `valid_to` passed two days
ago, an entity whose only document was forgotten, an entity with four live passages and no page
(Billing Service, from the corpus), and a page for the Mailer whose source document was then
revised.

| Check | Result |
|---|---|
| Lint recall on the five planted kinds (contradiction, expired-fact, orphan-entity, missing-page, stale-page) | 5/5 found, with addresses; 6 findings in total (the Billing Service page and one more missing page) |
| Omission check: a Billing Service page that leaves out the recorded fact "closes the books on the first business day" | flagged, exactly that statement |
| Corruption check: the same page plus an invented sentence ("written in Fortran … Reykjavik … twelve redundant generators") | flagged, exactly that sentence; the covering sentence passed |
| A complete page | applied, nothing omitted, nothing unsupported, `is_inference = 1`, sources recorded |
| Conflict item: the tool tries to keep the agent fact over the user fact | refused (a tool may not invalidate a more-trusted fact) |
| Conflict item: keep the user fact | applied; the agent fact is invalidated with `superseded_by`, not deleted |
| Raw rows (sources, documents, chunks) before and after the whole loop | byte-identical (SHA-256 over every row) |
| Fact rows | exactly one changed: the invalidation the agent asked for |

Thresholds, written down as starting points: a page item at 3 live passages; re-proposal after 2
new passages; a fact counts as covered at 75% of its content words (4+ letters, 5-letter stem);
a sentence (8+ content words) counts as unsupported below 50% overlap with its best source;
near-duplicate passages at word 3-gram Jaccard 0.75.

## The unit loop (`internal/compact/compact_test.go`)

Three passages about one entity produce a page item; a dry run shows the diff and one omission
and writes nothing; the real submit stores the page with three sources; the recurrence trigger
proposes nothing while nothing grew; revising a source marks the page stale with the reason,
lint lists it, a stale item rebuilds it to `built_from_rev = 2`; status counts one page and zero
stale.

## Not measured

The Ollama executor against a live model (none on this machine); page quality itself, which is
the calling agent's and which the string-level checks can only bound from below.
