How it works

Knowledge goes in with provenance. Answers come out with reasons.

Most agent memory is a black box: things go in, something comes back. memo-mcp is a small retrieval system you can read, inspect and measure — the agent and the human see the same numbers.

  1. 1
    Ingest ingest

    The agent hands over markdown it fetched or wrote. Same content is a no-op; changed content becomes a new revision.

  2. 2
    Remember remember

    Atomic facts with evidence and validity dates. Corrections supersede — the old fact stays as history.

  3. 3
    Search search

    Words, exact identifiers, meaning, facts and the mention graph — fused into one ranked list.

  4. 4
    Explain response_format: explain

    Every result carries its address, trust, per-arm ranks and the reason it ranked.

Why memo-mcp

Six guarantees a black box can't make.

Fully local

Embeddings run in-process, search runs in SQLite. After the one-time model download, nothing leaves the machine.

no cloud · no CGo · no telemetry

Explainable

Per-arm ranks, contributions, recency factor and a trace of which arms ran and where the list was cut.

memo-mcp explain "<q>" memo://chunk/n

Measurable

An eval harness reports recall, MRR and nDCG next to latency and tokens. Every change is checked against a baseline.

memo-mcp eval --explain-failures

Trust needs a human

Every record says where it came from and who vouched for it. Agents can ask to promote trust — only a person can grant it.

agent → user → curated

Aware of time

Ask what the knowledge base believed on any date. Superseded facts are kept; forgotten records say when and why.

search … as_of: 2026-03-01

Honest when empty

A question about nothing in the corpus returns zero results with a reason and a hint — not a page of noise.

weak band < 0.30 is dropped
Live demo

Five arms, one honest list.

Each retrieval arm ranks on its own; reciprocal rank fusion merges them at equal weight. Switch arms off and watch the order change — every score is shown.

    Versus built-in memory

    Built-in memory is a fine default. This is for when you need to know why.

    memo-mcp doesn't replace your assistant's memory — it gives you a retrieval system you can experiment on with your own data.

    Questionmemo-mcp
    Where does it run?On your machine, one SQLite file per project
    Why did this come back?Per-arm ranks and a written reason
    Can I tune ranking?Named profiles, every constant derived
    Is it getting better?Measured query by query against a baseline
    Can a human read it?Terminal, read-only web UI, markdown export
